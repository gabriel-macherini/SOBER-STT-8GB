# OpenCode Voice

Push-to-talk voice dictation for Windows. Double-tap and hold **CapsLock**, speak, release — the transcription is normalized by a local LLM and pasted into the focused window. Works in any app (Zed, VS Code, browser, Obsidian), not just the OpenCode TUI.

Pipeline (all local, zero cloud): mic → Parakeet STT → s1/Qwen normalization → clipboard + `Ctrl+V`.

## Files

| File | Role |
|---|---|
| `voice-tray.ahk` | Tray app: CapsLock gesture, overlay, lifecycle. Run this (or the desktop shortcut). |
| `runner.mjs` | Node daemon (`127.0.0.1:8791`): recording + STT + normalization HTTP API. Started by the tray app. |
| `rec-host.ps1` | Persistent mic recorder (winmm). Compiles once; per-dictation start costs ~80 ms instead of ~1.2 s. |
| `voice-*.ico` | Tray/overlay icons (idle/rec/proc), regenerated by `make-icons.ps1`. |
| `make-icons.ps1` | Regenerates the `.ico` files. |
| `warm.state` | Persisted "keep models loaded" toggle (`1`/`0`). Local state, not committed. |

## Requirements

- Windows + Node 22+ + [AutoHotkey v2](https://www.autohotkey.com/) (run `voice-tray.ahk` with `AutoHotkey64.exe`)
- The STT/LLM pipeline is reused from [opencode-voice](../opencode-voice) (`lib/stt.js`, `lib/llm-client.js`, `lib/local-llm-manager.js`), plus its local setup: `C:/Users/the_s/bin/rec.ps1`, `parakeet-cli` + ggml model, `llama-server` + s1/Qwen models. Paths are absolute — adapt the constants at the top of `runner.mjs` and `rec-host.ps1` to your machine.

## Gesture

Double-tap CapsLock and **hold** the second tap to record; release to transcribe + normalize + paste. CapsLock keeps working normally (`~` passthrough; a double-tap toggles caps twice = back to the original state). Tune at the top of `voice-tray.ahk`: `TAP_MAX` (400), `GAP` (800), `HOLD_MIN` (200) ms. Set `VOICE_DEBUG := true` for a gesture log in `%TEMP%\voice-tray.log`.

## Tray menu

- **Manter modelos carregados** (persisted in `warm.state`): keeps s1/Qwen up. Off = 1-min idle kill.
- **Abrir pasta**, **Sair** (kills the runner + `POST /kill`, freeing VRAM immediately).

Close the app to give CapsLock fully back to games; nothing stays resident except RAM-idle Node.

## VRAM policy (8 GB card)

Idle = zero VRAM. s1/Qwen spawn on demand and die 60 s after last use (or instantly on exit). Recording pre-warms **qwen only** in the background while Parakeet runs, so cold starts feel warm; s1 stays on demand to keep headroom next to Parakeet's ~3.2 GB peak.

## Measured latencies (RTX 3070, Ryzen 5600)

| Step | Cold | Warm |
|---|---|---|
| Record start (persistent host) | ~80 ms | ~80 ms |
| Parakeet transcribe (638 MB model, per-run process) | ~950 ms | ~950 ms |
| Qwen normalize (2.3 GB) | ~1550 ms | ~95 ms |
| s1 normalize (462 MB) | ~900 ms | ~65 ms |

End to end: ~1.1 s warm, ~2.5 s cold (cold LLM load overlaps transcription via pre-warm).

## Runner API

`POST /start` (record) · `POST /stop` → `{started, seq}` immediately, poll `GET /result?seq=N` · `POST /cancel` · `POST /kill` (drop LLM servers) · `POST /warm {enabled}` · `GET /health`. Phase (`recording/transcribing/normalizing/idle`) and mic level stream through `%TEMP%\opencode-stt.phase` / `.level` for the overlay; last I/O lands in `%TEMP%\opencode-stt.last.json`.
